# SAP AI Agents — Architecture Studio

Interactive customer demo based on the supplied SAP AI Agents technical architecture.

## Run

Open `index.html` in any modern browser. No build step, dependencies, API keys, or SAP connection are required.

## Modules

- Explore SAP BTP + AI Core, SAP BTP + public cloud AI, and Claude + SAP MCP.
- Inspect architecture components and trust boundaries.
- Play, pause, reset, or step through each request journey.
- Compare orchestrators, interfaces, credentials, endpoints, and billing.
- Explore illustrative SAP role-based authorization outcomes and trust setup notes.

All authorization outcomes are simulated. This is a reference demonstration, not a production SAP integration. Validate deployment-specific configuration before implementation.

## Validation

JavaScript syntax and browser checks passed for all three designs, component inspection, step navigation, authorization selection, and mobile overflow.
