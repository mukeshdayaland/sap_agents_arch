Corporate sign-in & subaccount trust

Federate IAS with Microsoft Entra ID and configure trust with the BTP subaccount. In the Claude design, Enterprise SSO and the connector's OAuth authorization are separate steps.

Destination & secure connectivity

Configure the destination for PrincipalPropagation. Connectivity routes the request with user identity through the Cloud Connector tunnel.

Certificates & SAP user mapping

Trust the Cloud Connector CA and system certificate in S/4HANA through STRUST. CERTRULE maps the short-lived X.509 certificate to the SAP user.
